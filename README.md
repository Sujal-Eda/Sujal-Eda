## Projects

**[AI Video Assistant](https://github.com/Sujal-Eda/AI_VIDEO_ASSISTANT)**
Transcribes YouTube or local video using Whisper, extracts key insights with an LLM, and enables Q&A over the content via a RAG pipeline. Stack: Whisper, LangChain, Mistral AI, ChromaDB, Streamlit.

**[KYC Document Quality Checker](https://github.com/Sujal-Eda/KYC_Real_Time_Quality_Checker)**
Real-time photo quality scoring for KYC document capture. Detects blur, glare, and angle issues live and triggers auto-capture when conditions are met. Stack: PyTorch, MobileNetV2, FastAPI, OpenCV, React.

**[MLOps CI/CD Pipeline](https://github.com/Sujal-Eda/MLOPS_CICD_DOCKER)**
Automated CI/CD workflow for a Dockerized Flask ML application using GitHub Actions with test coverage on each push. Stack: Docker, GitHub Actions, Flask, Python.

**[ETL Weather Pipeline](https://github.com/Sujal-Eda/MLOPS_AIRFLOW_PRACTICE)**
Automated ETL pipeline that fetches, transforms, and loads weather data using Apache Airflow running locally via Astronomer CLI and Docker. Stack: Airflow, Docker, Python.

**[E-commerce Price Optimization](https://github.com/Sujal-Eda/Ecommerce-Price-optimization)**
Demand prediction and price elasticity analysis to identify segment-specific pricing strategies that maximize revenue. Stack: Python, Scikit-learn, Pandas.

**[Hotel Revenue Forecasting](https://github.com/Sujal-Eda/Hotel-Revenue-Projection-model)**
Time-series forecasting model for hotel revenue using booking patterns, seasonality, and market trend features. Stack: Python, Jupyter.
